# Case 04 – Reviewa en Pull Request

## Scenario

En annan utvecklare har skickat in en Pull Request från branchen `case-04-feature-review` till `case-04-code-review`.

Innan ändringarna kan mergas behöver du granska koden och ge feedback.

## Din uppgift

1. Öppna Pull Requesten från `case-04-feature-review` till `case-04-code-review`.
2. Gå igenom de ändringar som har gjorts.
3. Lämna minst en kommentar på en rad i koden.
4. Slutför din review genom att välja:
   - **Approve**, eller
   - **Request changes**.

> **Tips:** Fundera på om koden är tydlig, följer projektets struktur och om något kan förbättras innan den mergas.
