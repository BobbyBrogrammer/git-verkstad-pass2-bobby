# Case 04 – Reviewa en Pull Request

## Scenario

En annan utvecklare har skickat in en Pull Request från branchen `feature-review` till `case-04-code-review`.

Innan ändringarna kan mergas behöver du granska koden och ge feedback.

## Din uppgift

- Öppna Pull Requesten från `feature-review` till `case-04-code-review`.
- Gå igenom de ändringar som har gjorts.
- Lämna minst en kommentar på en rad i koden.
- Slutför din review genom att välja:
  - **Approve**, eller
  - **Request changes**.

> **Tips:** Fundera på om koden är tydlig, följer projektets struktur och om något kan förbättras innan den mergas.
