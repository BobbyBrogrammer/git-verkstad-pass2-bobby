# Case 04 – Reviewa en Pull Request

## Scenario

En annan utvecklare har skickat in en Pull Request och vill att du granskar ändringarna innan de kan slås ihop med `main`.

## Din uppgift

- Öppna den tilldelade Pull Requesten.
- Gå igenom de ändringar som har gjorts.
- Lämna minst en kommentar på en rad i koden.
- Slutför din review genom att välja:
  - **Approve**, eller
  - **Request changes**.

> **Tips:** Fundera på om koden är tydlig, följer projektets struktur och om något kan förbättras.
