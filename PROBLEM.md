# Case 04 – Reviewa en klasskamrats Pull Request

## Scenario

En klasskamrat har öppnat en Pull Request med sina ändringar.

Nu är det din uppgift att granska klasskamratens kod innan ändringarna kan mergas till `main`.

## Din uppgift

1. Öppna din klasskamrats Pull Request.
2. Gå igenom ändringarna som har gjorts.
3. Lämna minst en kommentar på en rad i koden.
4. Ge konstruktiv feedback på något som är bra eller kan förbättras.
5. Slutför din review genom att välja:
   - **Approve**, eller
   - **Request changes**.

> **Tips:** Fundera på om koden är tydlig, fungerar som tänkt och om något kan förbättras innan den mergas.
